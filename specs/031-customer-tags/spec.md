# Feature Specification: 客户标签与细分

**Feature Branch**: `031-customer-tags`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P0-首批：客户标签体系 + 动态细分群组，支撑精准营销与筛选（业界全行业标配）。

## User Stories

### US1 - 标签管理 (P1)
管理员/有权限用户可创建标签（客户/线索/联系人通用），给客户打标（多标签），标签颜色可配；列表按标签筛选。

**验收**: 创建"VIP"标签（红色）→ 给客户 A 打标 → 客户列表按 VIP 筛选出 A。

### US2 - 动态细分群组 (P1)
基于条件（标签 + 字段 + 金额 + 最近跟进）定义动态细分（如"高价值+30天未跟进"），自动实时计算成员；细分可被邮件群发/列表筛选/报表引用。

**验收**: 建细分"高价值未跟进"（金额>10万 且 未跟进>30天）→ 成员自动匹配 → 列表/邮件群发可引用。

## Requirements

- **FR-001**: 标签 CRUD（名称/颜色/适用实体），客户可多标签。
- **FR-002**: 客户/线索/联系人打标与移除标；列表按标签筛选、标签聚合统计。
- **FR-003**: 动态细分：条件编辑器（标签 + 字段 + 金额 + 跟进时间 + 逻辑 AND/OR），保存后实时计算成员数。
- **FR-004**: 细分结果可导出/可作邮件群发收件人/可作报表过滤（与 030 联动）。
- **FR-005**: 权限：标签管理为营销管理权限（tag:manage）；打标按数据范围。

## Success Criteria

- SC-001: 标签 CRUD 正确率 100%（抽查 5 次）。
- SC-002: 打标/筛选正确率 100%（抽查 10 次）。
- SC-003: 动态细分成员计算正确率 100%——与手查结果一致（抽查 5 细分）。
- SC-004: 细分联动（群发/报表）正确率 100%。

## Edge Cases

- 标签删除时关联数据：解除关联不清除客户。
- 细分条件无匹配：成员 0 正常显示。
- 并发打标：乐观锁/幂等。

## Assumptions

- 标签表 tag + 关联表 customer_tag/lead_tag/contact_tag；细分表 segment（存 JSON 条件）。
- 细分成员实时计算（数据量中小规模可接受；大表后续可加缓存）。
- 标签颜色沿用 antd Tag 色板。
