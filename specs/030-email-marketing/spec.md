# Feature Specification: 邮件营销触达

**Feature Branch**: `030-email-marketing`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P0-首批：邮件营销触达——邮件模板 + 批量群发 + 打开/点击追踪，补齐营销闭环最后一块（业界 HubSpot/Zoho 标配）。

## User Stories

### US1 - 邮件模板管理 (P1)
管理员可创建/编辑邮件模板（标题 + 富文本正文 + 变量占位 {客户名}/{公司}/{电话}），模板分类（欢迎/促销/跟进/通知），支持预览渲染。

**验收**: 创建含 {客户名} 的"客户欢迎"模板 → 预览显示变量替换示例 → 可编辑/删除。

### US2 - 批量群发 (P1)
从客户细分/标签/筛选结果选收件人 + 模板 → 异步发送队列（带频控防滥用）；支持测试发送；记录每封发送状态（成功/失败/退信）与失败原因。

**验收**: 选 10 个客户 → 测试发送成功 → 正式发送 → 发送记录 10 封状态准确。

### US3 - 打开/点击追踪 (P2)
嵌入追踪像素 + 链接重定向，统计打开数/点击数/打开率/点击率；营销活动详情展示投放效果（复用 ROI 统计）。

**验收**: 发送后模拟打开 → 活动详情显示打开 1 次。

## Requirements

- **FR-001**: 邮件模板 CRUD，含标题/正文/变量占位/分类；正文富文本。
- **FR-002**: 批量群发：收件人（细分/标签/筛选）+ 模板 → 异步队列；测试发送；频控（批上限/间隔）。
- **FR-003**: 发送记录：每封状态 PENDING/SENT/FAILED/BOUNCED + 原因；活动维度汇总。
- **FR-004**: 打开/点击追踪：追踪像素 + 链接重定向；统计打开率/点击率。
- **FR-005**: SMTP 网关发送；未配置 SMTP 时降级"记录待发送 + 提示配置"（不阻塞其他功能）。
- **FR-006**: 权限：模板/群发为营销管理权限（新增 email:manage）；收件人限可见数据范围。

## Success Criteria

- SC-001: 模板 CRUD 正确率 100%（抽查 5 次）。
- SC-002: 群发任务正确率 100%——10 封状态准确（抽查 3 批次）。
- SC-003: 追踪正确率 100%——打开/点击计数准确（抽查 5 次）。
- SC-004: 无 SMTP 降级不阻塞。

## Edge Cases

- 收件人邮箱为空：跳过并记录。
- 频控超限：任务排队。
- 模板变量未匹配：保留原样。
- 退信：标记 BOUNCED 提示。

## Assumptions

- JavaMailSender + SMTP 环境变量；dev 无 SMTP 时控制台模拟。
- 自研追踪像素/重定向（不引第三方营销平台）。
- 批上限默认 500（配置化）。
- 表：email_template / email_campaign / email_send_log / email_track。
