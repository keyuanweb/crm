# Feature Specification: 公告与内部协作

**Feature Branch**: `037-announcements`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P1：团队公告 + 业务记录评论协作（@提及 + 通知），提升内部协作。

## User Stories

### US1 - 团队公告 (P1)
管理员/有权限用户发布公告（标题 + 富文本 + 置顶 + 过期时间）；全员可见（首页/通知中心展示未读公告）；已读标记。

**验收**: 发布"季度目标发布"公告置顶 → 全员首页可见 → 标记已读后不再提示未读。

### US2 - 记录评论协作 (P1)
业务记录（客户/线索/商机/工单）详情页支持评论：发表评论、@提及同事（触发 026 通知）、回复；评论时间线展示。

**验收**: 客户详情发评论 @张三 → 张三收到通知 → 点击跳回客户详情评论。

## Requirements

- **FR-001**: 公告 CRUD：标题/正文（富文本）/置顶/过期时间/发布范围（全员/角色）；列表 + 详情。
- **FR-002**: 已读：公告已读状态记录（user × announcement），未读角标。
- **FR-003**: 记录评论：客户/线索/商机/工单详情评论区（comment 表：实体类型/实体 id/内容/作者/@提及人）。
- **FR-004**: @提及：解析 @用户名 → 通知被提及人（026，带实体跳转）。
- **FR-005**: 权限：公告发布为系统管理权限（announcement:manage）；评论按数据范围（可见记录可评论）。
- **FR-006**: 通知中心展示未读公告（复用 NotificationCenter）。

## Success Criteria

- SC-001: 公告 CRUD + 置顶/过期正确率 100%（抽查 5 次）。
- SC-002: 已读标记正确率 100%（抽查 5 次）。
- SC-003: 评论 + @提及通知正确率 100%（抽查 5 次）。
- SC-004: 通知点击跳转目标记录正确率 100%。

## Edge Cases

- 公告过期自动隐藏（定时/查询时过滤）。
- @提及用户不存在：忽略不通知。
- 评论删除：仅作者/管理员；级联显示"已删除"。
- 记录删除后评论：随记录清理（逻辑删除）。

## Assumptions

- 公告表 announcement + 已读表 announcement_read；评论表 comment（多实体通用）。
- @提及正则解析（@用户名），通知复用 026（entityType=COMMENT + 跳转路径）。
- 公告入口：首页卡片 + 通知中心 Tab。
