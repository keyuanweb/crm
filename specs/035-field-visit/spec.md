# Feature Specification: 外勤拜访管理

**Feature Branch**: `035-field-visit`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P0-二批：外勤拜访计划 + 签到定位，配合 PWA 移动端补外勤场景闭环（业界纷享销客/销售易标配）。

## User Stories

### US1 - 拜访计划 (P1)
销售创建拜访计划（客户 + 拜访时间 + 目的/主题 + 预计时长），日历/列表视图展示；拜访前提醒（复用 026 通知）；拜访关联客户。

**验收**: 创建"拜访 Acme 客户-谈续约"计划 → 客户详情/日历可见 → 到点收到提醒。

### US2 - 签到打卡 (P1)
PWA 移动端拜访签到：到达定位打卡（记录经纬度/地址/时间）+ 现场拍照（可选）+ 拜访小结（记录拜访内容，同步写跟进）；支持计划外临时拜访。

**验收**: 拜访当日签到 → 记录位置/时间 → 填小结 → 客户跟进时间线出现该拜访记录。

## Requirements

- **FR-001**: 拜访计划 CRUD：客户/时间/目的/时长/状态（计划/进行中/已完成/取消）；列表 + 日历视图。
- **FR-002**: 拜访前提醒：计划时间前 X 分钟推送通知（026）。
- **FR-003**: 签到：移动端定位打卡（经纬度 + 反向地址 + 时间），可选拍照；防重复签到（同一计划仅一次）。
- **FR-004**: 拜访小结：签到后填内容 → 自动生成跟进记录（复用 follow_up）。
- **FR-005**: 拜访统计：按销售/客户/月份统计拜访次数与完成率。
- **FR-006**: 权限：拜访为销售操作权限（visit:manage 或复用 lead 权限）；数据范围隔离。

## Success Criteria

- SC-001: 拜访计划 CRUD 正确率 100%（抽查 5 次）。
- SC-002: 签到记录正确率 100%——经纬度/时间/地址准确（抽查 5 次）。
- SC-003: 小结转跟进正确率 100%——客户时间线出现记录（抽查 5 次）。
- SC-004: 重复签到拦截正确率 100%。
- SC-005: 移动端（PWA）可完成签到（冒烟）。

## Edge Cases

- 无定位权限/离线：签到降级（记录时间 + 手动地址），恢复后同步。
- 拜访时间已过：允许补签到（标记"补签"）。
- 拜访取消：计划状态更新，不生成跟进。
- 定位偏差：允许签到（记录坐标，不强制地理围栏）。

## Assumptions

- 拜访表 field_visit（计划）复用 follow_up 存小结；签到用浏览器 Geolocation API。
- PWA 已有（027），本功能在移动端页面加"拜访"入口。
- 不强制地理围栏（避免伪定位争议，记录坐标即可）。
