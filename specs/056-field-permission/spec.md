# 功能规格：字段级读写权限模块

**功能分支**: `056-field-permission`

**创建日期**: 2026-08-25

**状态**: 草稿

**输入**: 043 差距分析 P2 建议——"字段级读写权限（按角色隐藏/只读字段）"。对标成熟 CRM（Salesforce Field-Level Security / 纷享销客字段权限）：为敏感/关键字段（如成本价、提成、手机号）配置按角色的可见性与可编辑性，实现比菜单/操作权限更细粒度的数据保护。

## 用户场景与测试（必填）

### 用户故事 1 - 字段权限配置（优先级：P0）

管理员为（角色 × 实体类型 × 字段）配置权限：隐藏 / 只读 / 可编辑；未配置字段默认可编辑。

**优先级理由**: 配置是权限控制的前提，P0 最先交付。

**独立测试**: 配置某角色对某字段只读 → 该角色查看可见但不可编辑。

**验收场景**:

1. **Given** 管理员配置角色 SALES 对客户"手机号"字段只读，**When** 保存，**Then** 配置生效。
2. **Given** 配置某字段对某角色隐藏，**When** 该角色查看表单，**Then** 字段不显示。
3. **Given** 未配置的字段，**When** 任意角色操作，**Then** 默认可编辑（不限制）。

---

### 用户故事 2 - 字段权限应用（优先级：P0）

字段列表接口按当前角色返回权限标记（hidden/readOnly）；保存接口拒绝隐藏字段的写入（服务端强制）。

**优先级理由**: 权限需前后端一致（界面隐藏 + 服务端拦截），P0 交付。

**独立测试**: 只读字段保存被拒；隐藏字段写入被拒。

**验收场景**:

1. **Given** 字段对角色只读，**When** 该角色提交含该字段的修改，**Then** 服务端拒绝（422 字段只读）。
2. **Given** 字段对角色隐藏，**When** 提交含该字段值，**Then** 服务端拒绝（422 字段隐藏）。
3. **Given** 可编辑字段，**When** 提交，**Then** 正常保存。

### 边界情况

- ADMIN 角色恒不受限（全字段可编辑）。
- 权限仅作用于自定义字段（内置字段不在 v1 范围，后续扩展）。
- 隐藏/只读优先于"可编辑"（同一字段多角色取各自配置）。

## 需求（必填）

### 功能需求

#### 配置

- **FR-F01**: 系统必须支持按（角色、实体类型、字段）配置权限：HIDDEN / READ_ONLY / EDITABLE。
- **FR-F02**: 系统必须支持权限配置 CRUD（配置仅 ADMIN）。
- **FR-F03**: 未配置字段默认 EDITABLE。

#### 应用

- **FR-F04**: 字段列表接口必须返回当前角色的权限标记（hidden/readOnly）。
- **FR-F05**: 保存接口必须拒绝 HIDDEN 字段写入（422）。
- **FR-F06**: 保存接口必须拒绝 READ_ONLY 字段修改（422）。
- **FR-F07**: ADMIN 恒不受限。

#### 权限与约束

- **FR-F08**: 配置仅 ADMIN；应用对全部角色生效。

### 关键实体（涉及数据）

- **字段权限（FieldPermission）**: 新增实体；角色 id、实体类型、字段 id、权限（HIDDEN/READ_ONLY/EDITABLE）。
- **自定义字段（CustomField，复用）**: 字段定义。

## 成功标准（必填）

### 可度量结果

- **SC-F01**: 只读/隐藏字段保存拦截正确率 100%（抽查 5 次）。
- **SC-F02**: 字段列表权限标记正确率 100%（抽查 5 个角色）。
- **SC-F03**: ADMIN 不受限（抽查 3 次）。
- **SC-F04**: 前端 typecheck / lint / build 通过，后端 verify 通过，无回归。

## 假设

- v1 仅作用于自定义字段（内置字段权限后续扩展）。
- 权限按角色（不按用户/部门）；每角色一配置。
- 配置为覆盖式（角色+实体+字段 唯一）。

## 依赖
