### 1.1 `zh:check` 的用法

```bash
cd frontend
pnpm zh:check                # 门禁：三分支双向校验 + 反假绿下限 + 口径边界自证
node scripts/check-zh.mjs --list   # 逐文件逐行清单 = 本批工作单，也是下一批的入口
```

`.i18n-keys/find-hardcoded-zh.mjs` 是**口径真源**（被 gitignore、未入库）；本项的
`scripts/check-zh.mjs` **把同一套取法搬进版本库**，并叠加台账与边界自证 —— 任何人、任何机器
都能算出同一个数（这是本项对可复现性的核心修补）。

## 2 口径边界自证（必做，且必须写进留痕）

`zh:check` 会**信息性**打印一行「本脚本判 N；**口径外另有 M 处**（全角标点 / 带插值模板串）」。
**独立复核一次 M**：用一条与主口径**不同**的取法量同一批节点范围，**两个读数必须相符**。

```bash
# 主口径（AST，只有 StringLiteral / NoSubstitutionTemplateLiteral / JsxText）
cd frontend && node scripts/check-zh.mjs

# 次级口径（同一批 AST 节点，正则放宽到 全角标点 + 全角字母数字，并额外收 TemplateExpression）
#   ⇒ 两个读数相减即为 M；M 必须与脚本印出来的那一行相符
```

⚠️ **这一行不是门禁**：它**不进 `problems`、不改退出码**，**留痕里必须写明它不判**。
理由：任何扫描器对自己的盲区**自证不了**（漏掉的那项不会出现在结果里），所以边界必须被**印出来**。

**已知两个盲区**（完整清单见 `research.md` §1.1）：**全角标点** `：，（）；`（在 U+4E00–9FFF 之外）
与**带插值的模板串** `` `${t('…')} ${n} 条` ``（是 `TemplateExpression`）—— 两者既有脚本都数不到。

## 3 定向破坏（**7 条**，逐条转红后**还原**）

每条都要：① 记录破坏前的基准（`git diff` 为空）；② 观测到**具体哪条分支/规则**转红（**点得出名字**）；
③ 还原并复跑转绿；④ **破坏期间不提交**。

| # | 破坏 | 期望转红 | 证明了什么 |
|---|---|---|---|
| D1 | 把清零过的一处**改回中文字面量** | `zh:check` **第一分支：未登记命中** | **防回潮的核心** |
| D2 | 把某条台账的 `count` **加 1** | `zh:check` **第二分支：count 多了** | 台账不能虚报 |
| D3 | 把某条台账的 `count` **减 1** | `zh:check` **第三分支：count 少了** | 清零被机器强制 |
| D4 | **删掉某条台账**（文件仍有命中） | 第一分支红（命中无处登记） | 台账覆盖现状 |
| D4-ii | 只把某条 `count` **改为 0** 而文件**真清零** | 第三分支红 | 已归零也受管 |
| D5 | 让扫描器**退化**（摘掉 `JsxText` 分支） | **`MIN_CANDIDATES.ZH` 自检失败** | **反假绿有牙** |
| D6 | **反向**：把 `App.tsx` 的 `aria-label` 改回裸字符串 | `ui:check` 的 **R6** | 摘白名单 ≠ 关规则 |
| D7 | **反向**：给 `en.ts` 加一个 `zh-CN.ts` 没有的键 | `i18n:check` **双向对齐** | 双语必须同批 |

⚠️ **D5 是「护栏在输入为空时通过等于没有护栏」的实测**。`MIN_CANDIDATES` 的存在意义就是让
「扫描器坏了、什么都扫不到」**当场转红**，而不是安静地报 0 处。
⚠️ **D6/D7 的期望也是红**：它们证明的不是「我的护栏有牙齿」，而是「**这两条既有护栏没被我摘松**」。
⚠️ **D4 要两个方向各做一次**（删条目 / count 归零）—— 只做一个的话，一个**单向**台账也会全绿。

### 3.1 还原判据

前端文件因 `core.autocrlf` 在 checkout 时可能写成 CRLF ⇒ `sha1sum <path>` 会**假不等**。
判**内容级**相等要用：

```bash
git cat-file -p HEAD:<path> | sha1sum      # 与破坏前的值比
```

**不称「逐字节一致」**（照 097 §C(ii) 的既有订正）。
