# Quickstart: 系统管理菜单提升与重组模块验证指南

**Branch**: `042-menu-system-flatten`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）；后端运行于 8081。
- 本模块无后端/迁移变更，无需重启后端。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过。

### 2. 手动验证（一级分组）

1. 以 admin 登录，查看左侧菜单。
2. **预期**：直接显示三个一级分组（非系统管理嵌套内）：
   - 系统管理：用户管理、角色权限、部门
   - 流程与配置：工作流、审批流配置、SLA 策略、合同模板、自定义字段
   - 审计与维护：标签与细分、审计日志、回收站
3. 无二级嵌套，展开任一分组即显示配置项。

### 3. 手动验证（自动展开）

- 分别进入 /users（系统管理）、/workflows（流程与配置）、/tags（审计与维护），对应分组自动展开并高亮。

### 4. 移动端

- 窗口 <768px：全部菜单拍平为普通项，无分组嵌套、无报错。

## 契约核对

- 无后端接口变更，契约无更新。
