# 功能规格：集成中心模块

**功能分支**: `058-integration-hub`

**创建日期**: 2026-08-25

**状态**: 草稿

**输入**: 043 差距分析 P2 建议——"集成中心（第三方连接器框架：钉钉/企微/企业微信通知、日历同步）"。对标成熟 CRM（纷享销客/销售易集成中心）：为业务用户提供**第三方通道管理**——预置常见通道（企业微信群机器人、钉钉群机器人、自定义 Webhook），系统业务事件（工单分配、线索创建、审批待办等）可推送到配置的通道，实现"业务消息触达企业 IM"。

## 用户场景与测试（必填）

### 用户故事 1 - 通道配置与管理（优先级：P0）

管理员配置第三方通知通道（类型 + 名称 + Webhook URL + 启用）；通道列表/编辑/删除。

**优先级理由**: 通道是推送的目标，先配置才能推送，P0 最先交付。

**独立测试**: 配置企业微信通道 → 列表可见 → 编辑/停用生效。

**验收场景**:

1. **Given** 管理员配置企业微信群机器人通道（Webhook URL），**When** 保存，**Then** 通道创建成功且启用。
2. **Given** 通道列表，**When** 查看，**Then** 展示类型/名称/状态。
3. **Given** 通道停用，**When** 触发事件，**Then** 不推送该通道。

---

### 用户故事 2 - 事件推送（优先级：P0）

系统业务事件（工单分配/线索创建/审批待办）触发时，将消息推送到全部启用通道；推送记录可查（复用 055 WebhookDelivery）。

**优先级理由**: 推送是集成价值落地（工单/审批消息触达 IM），与故事 1 共同构成 P0。

**独立测试**: 配置通道 → 工单分配 → 推送记录生成。

**验收场景**:

1. **Given** 通道已配置启用，**When** 工单被分配，**Then** 消息推送到通道（记录生成）。
2. **Given** 推送记录，**When** 查看，**Then** 展示通道/事件/状态/时间。
3. **Given** 无启用通道，**When** 事件发生，**Then** 安静跳过。

### 边界情况

- 通道 URL 校验（http/https）。
- 推送格式：JSON 文本（企业微信/钉钉 markdown 兼容的简化格式）。
- 推送失败重试（复用 055 退避重试机制）。
- 事件子集：TICKET_ASSIGNED（工单分配）、LEAD_CREATED（线索创建）、APPROVAL_PENDING（审批待办）。

## 需求（必填）

### 功能需求

#### 通道管理

- **FR-I01**: 系统必须支持通道 CRUD（类型/名称/Webhook URL/启用）。
- **FR-I02**: 系统必须预置通道类型（WECHAT_WORK 企业微信/DINGTALK 钉钉/CUSTOM 自定义）。
- **FR-I03**: 系统必须支持通道启停。

#### 事件推送

- **FR-I04**: 系统必须在业务事件触发时推送消息到全部启用通道。
- **FR-I05**: 系统必须支持事件子集：TICKET_ASSIGNED / LEAD_CREATED / APPROVAL_PENDING。
- **FR-I06**: 系统必须记录推送结果（复用 055 WebhookDelivery）。
- **FR-I07**: 无启用通道时安静跳过。

#### 权限与约束

- **FR-I08**: 通道配置：仅 ADMIN。
- **FR-I09**: 推送格式为 JSON 文本（简化 markdown 兼容）。

### 关键实体（涉及数据）

- **集成通道（IntegrationChannel）**: 新增实体；类型、名称、Webhook URL、启用状态。
- **推送记录（复用 WebhookDelivery）**: 通道作为订阅目标（复用 055 机制）。

## 成功标准（必填）

### 可度量结果

- **SC-I01**: 通道 CRUD 正确率 100%（抽查 5 次）。
- **SC-I02**: 事件推送触发正确率 100%（抽查 3 个事件）。
- **SC-I03**: 停用通道不推送（抽查 3 次）。
- **SC-I04**: 前端 typecheck / lint / build 通过，后端 verify 通过，无回归。

## 假设

- v1 复用 055 WebhookService 推送机制（通道作为订阅，事件类型映射到 Webhook event）。
- 推送格式为纯文本 JSON（不深度适配企业微信/钉钉 markdown 卡片）。
- 通道为 Webhook 型（非 OAuth 应用接入，v1 简化）。

## 依赖

- 开放平台（055-open-platform）Webhook 推送/记录机制。
