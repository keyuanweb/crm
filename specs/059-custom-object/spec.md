# 功能规格：自定义对象模块

**功能分支**: `059-custom-object`

**创建日期**: 2026-08-25

**状态**: 草稿

**输入**: 043 差距分析 P3 建议——"低代码自定义对象（元数据驱动建模）"。对标成熟 CRM（Salesforce Custom Objects / Zoho 自定义模块）：当内置实体（客户/线索/商机等）无法覆盖业务场景（如"项目""活动""门店"等自定义业务对象）时，允许管理员**定义新对象**（名称/编码/字段集），并为对象创建/查询记录，实现元数据驱动的业务扩展。

## 用户场景与测试（必填）

### 用户故事 1 - 对象定义（优先级：P0）

管理员定义自定义对象（名称 + 编码 + 字段集：字段名/类型/必填/选项），对象启用后可用。

**优先级理由**: 对象定义是建模基础，先定义才能录数据，P0 最先交付。

**独立测试**: 定义"项目"对象（含名称/负责人/状态字段）→ 启用 → 对象列表可见。

**验收场景**:

1. **Given** 管理员定义对象"项目"（编码 PROJECT，字段：名称文本/负责人文本/状态下拉），**When** 保存，**Then** 对象定义成功且启用。
2. **Given** 对象列表，**When** 查看，**Then** 展示对象名称/编码/字段数/状态。
3. **Given** 对象字段定义，**When** 校验，**Then** 字段类型合法（TEXT/NUMBER/DATE/SELECT）、必填/选项有效。

---

### 用户故事 2 - 对象记录管理（优先级：P0）

对象启用后支持记录 CRUD（动态表单：按对象字段定义渲染）；记录列表/详情/搜索。

**优先级理由**: 记录管理是对象的价值落地（用自定义对象承载业务数据），与故事 1 共同构成 P0。

**独立测试**: 创建"项目"记录 → 列表可见 → 编辑 → 删除。

**验收场景**:

1. **Given** 对象已启用，**When** 创建记录（提交字段值），**Then** 记录保存成功。
2. **Given** 记录列表，**When** 查看，**Then** 展示记录字段值（按对象字段）。
3. **Given** 记录，**When** 编辑/删除，**Then** 操作生效。

### 边界情况

- 对象编码唯一（防冲突）；编码用大写字母/数字/下划线。
- 字段定义存储 JSON（对象定义内嵌字段集）。
- 记录值 JSON 存储（字段值键值对）。
- 停用对象：不可新建记录，既有记录可查。
- 删除对象：逻辑删除（保留记录历史）。

## 需求（必填）

### 功能需求

#### 对象定义

- **FR-C01**: 系统必须支持自定义对象定义（名称、编码、字段集、启用）。
- **FR-C02**: 系统必须支持对象 CRUD（配置仅 ADMIN）。
- **FR-C03**: 系统必须校验字段类型/必填/选项合法性。

#### 记录管理

- **FR-C04**: 系统必须支持对象记录 CRUD（动态字段值）。
- **FR-C05: 系统必须支持记录列表/详情/搜索（按字段值）。
- **FR-C06**: 停用对象不可新建记录；既有记录可查。

#### 权限与约束

- **FR-C07**: 对象定义：仅 ADMIN；记录管理：ADMIN + SALES（+ 可配置）。

### 关键实体（涉及数据）

- **自定义对象（CustomObject）**: 新增实体；名称、编码（唯一）、字段集 JSON、启用、逻辑删除。
- **对象记录（CustomObjectRecord）**: 新增实体；对象 id、记录值 JSON、创建人/时间。

## 成功标准（必填）

### 可度量结果

- **SC-C01**: 对象定义/校验正确率 100%（抽查 5 个）。
- **SC-C02**: 记录 CRUD 正确率 100%（抽查 10 条）。
- **SC-C03**: 搜索按字段值命中正确（抽查 5 次）。
- **SC-C04**: 前端 typecheck / lint / build 通过，后端 verify 通过，无回归。

## 假设

- 对象字段集内嵌于对象定义 JSON（不单独建字段表，简化 v1）。
- 记录值为 JSON 键值对存储（按字段名）。
- 对象类型不参与关系（不关联内置实体，v1 独立对象）。
