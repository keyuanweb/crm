# Quickstart: 前端体验优化模块验证指南

**Branch**: `039-dashboard-ux`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）；后端运行于 8081。
- 本模块无后端/迁移变更，无需重启后端。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过（无回归）。

### 2. 手动验证（菜单切换无闪烁）

1. 刷新页面并登录。
2. 等待 2~3 秒（预加载完成后，SC-UX01 ≤5 秒）。
3. 依次快速点击左侧菜单：客户 → 线索 → 商机 → 统计 → 工单 → 合同。
4. **预期**: 每次切换内容区直接呈现目标页面，无居中转圈、无空白闪现、无高度塌陷跳动。

### 3. 手动验证（首次加载兜底）

- 开发者工具 Network 面板设置 Slow 3G，登录后**立即**点击尚未访问的菜单项。
- **预期**: 显示同高灰色骨架（非居中 Spin），随后页面内容填充，无布局跳动。

### 4. 手动验证（客户分析卡片）

- 桌面宽度（≥992px）打开首页 `/stats`：客户分析卡三统计项横排整齐，卡片高度与内容匹配、无大块留白。
- 浏览器窗口缩至 <768px：统计项垂直堆叠、不挤压换行；跟进活动卡与公告卡高度自适应。
- 公告为空时：公告卡占位合理，跟进活动卡正常填充。

## 契约核对

- 本模块无后端接口变更，契约无更新。
- 前端路由、菜单、页面均沿用既有结构。
