# Feature Specification: 全局搜索

**Feature Branch**: `032-global-search`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P0-首批：跨客户/线索/联系人/商机/工单/产品统一搜索，顶栏全局搜索框（业界 Salesforce 标配）。

## User Stories

### US1 - 全局搜索 (P1)
顶栏全局搜索框：输入关键字 → 下拉即时结果（按实体分组，客户/线索/联系人/商机/工单/产品各 Top N）→ 点击跳转详情/列表；支持多关键字（空格分隔 AND）。

**验收**: 输入"Acme" → 下拉显示客户/线索/商机分组结果 → 点击客户跳详情。

### US2 - 搜索直达 (P2)
回车进入全局搜索结果页（聚合列表 + 实体 Tab 切换 + 高亮关键字 + 按数据范围过滤）。

**验收**: 回车 → 结果页显示聚合列表 → 切"商机"Tab 只看商机。

## Requirements

- **FR-001**: 顶栏搜索框（Header 内），输入防抖即时下拉（≥2 字符触发）。
- **FR-002**: 搜索范围：客户（名称/公司/联系人/电话）、线索（名称/公司）、联系人（姓名/电话）、商机（名称/客户）、工单（标题）、产品（名称/编码）——均受数据权限过滤。
- **FR-003**: 下拉结果按实体分组，每组 Top 5；点击跳转详情或列表。
- **FR-004**: 结果页：聚合 Tab（全部/客户/线索/联系人/商机/工单/产品）+ 关键字高亮 + 分页。
- **FR-005**: 多关键字空格 AND；LIKE 匹配；性能：索引或 LIMIT 限制。

## Success Criteria

- SC-001: 下拉即时结果正确率 100%（抽查 10 关键字）。
- SC-002: 结果页 Tab 过滤正确率 100%（抽查 5 次）。
- SC-003: 数据权限隔离正确率 100%——SALES 仅见可见数据（抽查 5 次）。
- SC-004: 搜索响应 ≤ 500ms（中小数据量）。

## Edge Cases

- 关键字为空/过短：不触发。
- 无匹配：显示空态。
- 特殊字符：转义处理。
- 大表性能：LIKE 前缀优化或分片查询。

## Assumptions

- 搜索走后端聚合接口（非全文检索引擎，避免引入 ES 依赖）。
- 每实体 LIMIT 20（下拉 5/页 20）。
- 表均已有相关字段索引（可补 idx）。
