# Quickstart: 系统管理子菜单细分模块验证指南

**Branch**: `041-menu-system-split`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）；后端运行于 8081。
- 本模块无后端/迁移变更，无需重启后端。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过。

### 2. 手动验证（二级分组）

1. 以 admin 登录，展开"系统管理"组。
2. **预期**：显示 3 个二级子组：
   - 组织与权限：用户管理、角色权限、部门
   - 流程与配置：工作流、审批流配置、SLA 策略、合同模板、自定义字段
   - 审计与维护：标签与细分、审计日志、回收站
3. 展开各子组，项归属正确；展开后无平铺 11 项。

### 3. 手动验证（路由可达）

- 系统管理下抽查 3 项（每子组 1 项）点击，目标页面正常、菜单高亮且父级展开。

### 4. 移动端

- 窗口 <768px：系统管理拍平为普通项（无二级嵌套），全部入口可点、无报错。

## 契约核对

- 无后端接口变更，契约无更新。
