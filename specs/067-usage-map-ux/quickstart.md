# Quickstart Guide: 使用地图视觉样式优化

## 前置条件

- 后端服务运行中（端口 8081）
- 前端服务运行中（端口 5173）
- 已安装 `@antv/g6` v5

## 手动测试步骤

### 1. 启动前端服务

```bash
cd E:\code\crm\frontend
pnpm dev
```

### 2. 打开使用地图

访问 http://localhost:5173/usage-map

### 3. 验证节点样式增强

## 常见问题

### Q: 节点阴影不显示？

A: 检查 G6 版本是否支持 `shadow` 属性。如果不支持，降级到使用 `lineWidth` 模拟阴影效果。

### Q: 弹窗遮挡流程图？

A: 调整弹窗位置（右滑出）或使用 Drawer（右侧滑出）。

### Q: 移动端动画卡顿？

A: 使用 CSS `transform`（GPU 加速），限制动画复杂度。
