# 功能规格：邮件账户与同步记录（Email Sync）模块

**功能分支**: `062-email-sync`

**创建日期**: 2026-08-25

**状态**: 草稿

**输入**: 043 差距分析 P3 建议——"邮件双向同步（Outlook/Gmail，需外部 OAuth 凭证与 IMAP/API 对接）"。真实双向同步需外部邮箱服务凭证；本模块 v1 提供**邮件账户配置与同步记录框架**：管理员配置邮件账户（邮箱地址/显示名/IMAP/SMTP 参数/启用/默认发件），同步记录管理（方向/主题/收发件人/状态/时间），并提供**模拟同步端点**（生成同步记录，验证完整链路）；真实 IMAP/OAuth 接入留作外部集成（数据模型与接口就绪）。

## 用户场景与测试（必填）

### 用户故事 1 - 邮件账户配置（优先级：P0）

管理员配置邮件账户（邮箱地址、显示名、IMAP 主机/端口、SMTP 主机/端口、启用、默认发件），账户列表/编辑/删除。

**优先级理由**: 账户是同步的基础，先配置才能同步，P0 最先交付。

**独立测试**: 配置账户 → 列表可见 → 默认发件标记 → 删除。

**验收场景**:

1. **Given** 管理员配置邮箱账户（sales@corp.com + IMAP/SMTP 参数），**When** 保存，**Then** 账户创建成功。
2. **Given** 账户列表，**When** 查看，**Then** 展示邮箱/显示名/协议参数/默认发件标记。
3. **Given** 默认发件账户唯一，**When** 设置新默认，**Then** 原默认自动取消。

---

### 用户故事 2 - 同步记录与模拟同步（优先级：P0）

邮件同步记录列表（方向/主题/收发件人/状态/时间）；模拟同步端点触发一次"拉取"生成同步记录（验证链路）。

**优先级理由**: 同步记录是双向同步的价值落地，模拟同步可完整验证链路，与故事 1 共同构成 P0。

**独立测试**: 模拟同步 → 同步记录生成 → 列表可见。

**验收场景**:

1. **Given** 账户已配置，**When** 调用模拟同步，**Then** 生成一条同步记录（INBOUND）。
2. **Given** 同步记录列表，**When** 查看，**Then** 展示方向/主题/收发件人/状态/时间。
3. **Given** 记录，**When** 删除，**Then** 删除生效。

### 边界情况

- 同步方向：INBOUND（收件）/ OUTBOUND（发件）。
- 同步状态：SYNCED（已同步）/ FAILED（失败）。
- 邮箱地址格式校验；默认发件账户唯一。
- 真实 IMAP/OAuth 同步 v1 不做（模拟端点生成记录验证链路）。

## 需求（必填）

### 功能需求

#### 账户配置

- **FR-E01**: 系统必须支持邮件账户 CRUD（邮箱/显示名/IMAP/SMTP/启用/默认发件）。
- **FR-E02**: 系统必须校验邮箱格式。
- **FR-E03**: 系统必须保证默认发件账户唯一（新默认自动取消原默认）。

#### 同步记录

- **FR-E04**: 系统必须支持同步记录列表（按账户/方向/时间筛选）。
- **FR-E05**: 系统必须提供模拟同步端点（生成同步记录）。
- **FR-E06**: 系统必须支持同步记录删除。

#### 权限与约束

- **FR-E07**: 账户配置：仅 ADMIN；同步记录查看：ADMIN + SALES。

### 关键实体（涉及数据）

- **邮件账户（MailAccount）**: 新增实体；邮箱、显示名、IMAP/SMTP 参数、启用、默认发件。
- **同步记录（MailSyncRecord）**: 新增实体；账户 id、方向、主题、收发件人、状态、时间、外部 id 占位。

## 成功标准（必填）

### 可度量结果

- **SC-E01**: 账户 CRUD/默认唯一正确率 100%（抽查 5 次）。
- **SC-E02**: 模拟同步生成记录正确率 100%（抽查 3 次）。
- **SC-E03**: 邮箱格式校验正确（抽查 3 次）。
- **SC-E04**: 前端 typecheck / lint / build 通过，后端 verify 通过，无回归。

## 假设

- v1 不接真实 IMAP/OAuth（模拟同步验证链路；数据模型含外部邮件 id 占位，真实对接时填充）。
- 账户密码不存储明文（v1 仅存储 IMAP/SMTP 参数，凭证留外部密钥管理）。
- 同步频率/定时任务不在 v1（手动模拟同步触发）。
