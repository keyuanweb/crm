# Quickstart: 体验优化批次验证指南

**Branch**: `065-ux-optimizations`

## 前置条件

- 后端 8081（jar 含 d927645 聚合修复）、前端 5173 运行中。

## 验证场景

### 1. 首页销售预测去重

- 创建同阶段多条商机 → 首页销售预测该阶段仅一行（金额为合计）。
- 前端兜底：即使接口返回逐商机明细也不重复。

### 2. 客户详情页

- 点"编辑客户"→ 改名称/状态 → 保存 → 页面即时刷新（无需手动刷新）。
- 电话/邮箱可点击拨号/发信；窄屏单列。

### 3. 产品多币种价

- 编辑产品 → 添加 USD 价 140 → 保存 → 多币种页/价格视图含配置价。
- 移除该币种 → 保存 → 价格被删除。

### 4. 布局

- 宽屏内容 1680px 居中；顶栏折叠按钮切换侧栏；访问 `/xyz` 显示 404；切换页面滚动复位 + 淡入。

### 5. 文案/显示

- 首页问候显示"你好，admin 👋"；客户列表电话完整显示。
