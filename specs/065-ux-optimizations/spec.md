# 功能规格：体验优化批次（UX Optimizations）

**功能分支**: `065-ux-optimizations`

**创建日期**: 2026-08-26

**状态**: 草稿

**输入**: 用户反馈驱动的界面体验优化（已完成实现，本模块补 SDD 文档与验证记录）：
1. 首页销售预测出现同阶段重复数据；
2. 客户详情页缺编辑入口、头部信息单薄、移动端不响应；
3. 产品编辑页未集成多币种价格（057）；
4. 整体布局：内容区无限制（大屏行过长）、滚动条默认、间距不统一、无 404 页、页面切换无过渡；
5. 首页问候 i18n 插值 `{name}` 未替换（单花括号 vs i18next 双花括号）；
6. 客户列表手机号脱敏导致"显示不全"（按用户要求列表显示完整号）；
7. 列表页搜索框与顶部内容紧贴，缺少间距（ProTable search form 上方有 Space/Row/Card 时）。

## 用户场景与测试（必填）

### 用户故事 1 - 首页销售预测去重（优先级：P0）

销售预测按阶段唯一展示，同阶段多商机不重复行。

**独立测试**: 同阶段多条商机 → 预测区域该阶段仅一行且金额为合计。

**验收场景**:

1. **Given** 多个商机处于同一阶段，**When** 查看首页销售预测，**Then** 该阶段仅显示一行（金额/加权为合计）。
2. **Given** 不同阶段商机，**When** 查看，**Then** 各阶段分别一行。

---

### 用户故事 2 - 客户详情页体验（优先级：P0）

详情页支持就地编辑核心字段、电话/邮箱可点击、健康度徽章、移动端单列。

**独立测试**: 详情页编辑 → 保存 → 页面即时刷新。

**验收场景**:

1. **Given** 详情页，**When** 点"编辑客户"，**Then** 打开编辑表单（名称/公司/联系人/电话/邮箱/地址/状态/备注）。
2. **Given** 保存后，**When** 查看，**Then** 页面数据即时更新（React Query 失效刷新）。
3. **Given** 窄屏，**When** 查看基本信息，**Then** 单列展示不挤压。

---

### 用户故事 3 - 产品页多币种价集成（优先级：P0）

产品编辑 Modal 内可直接配置各币种价格（057），保存同步新增/更新/删除。

**独立测试**: 编辑产品配置 USD 价 → 保存 → 价格视图含配置价。

**验收场景**:

1. **Given** 编辑产品，**When** 添加币种价（USD 140.00），**Then** 行可保存。
2. **Given** 移除已配置币种，**When** 保存，**Then** 该币种价被删除（差集计算）。
3. **Given** 未配置币种，**When** 查看，**Then** 提示按汇率自动折算。

---

### 用户故事 4 - 整体布局优化（优先级：P1）

内容区限宽居中、滚动条美化、卡片间距统一、桌面侧栏可折叠、404 页、路由切换滚动复位与淡入过渡。

**独立测试**: 布局要素生效且无回归。

**验收场景**:

1. **Given** 宽屏，**When** 查看任意页，**Then** 内容区最大 1680px 居中，两侧留白适度。
2. **Given** 桌面端，**When** 点顶栏折叠按钮，**Then** 侧栏 200px ↔ 64px 切换。
3. **Given** 访问不存在路径，**When** 打开，**Then** 显示 404 页（登录后带菜单）。
4. **Given** 切换页面，**When** 导航，**Then** 内容区滚动复位顶部且页面淡入。

---

### 用户故事 5 - 文案与显示修正（优先级：P1）

首页问候插值正确显示用户名；客户列表显示完整手机号/邮箱。

**独立测试**: 首页显示"你好，admin 👋"；列表显示完整号码。

**验收场景**:

1. **Given** 登录，**When** 查看首页，**Then** 问候含真实用户名（非 `{name}` 字面量）。
2. **Given** 客户列表，**When** 查看电话列，**Then** 显示完整号码（非 `139****1111`）。

---

### 用户故事 6 - 列表页搜索框间距（优先级：P1）

列表页 ProTable 搜索框与顶部内容（Tab 按钮/统计卡片/说明文字）之间需要 16px 间距，避免视觉紧贴。

**独立测试**: 打开任意有顶部内容的列表页 → 搜索框与上方内容有 16px 间距。

**验收场景**:

1. **Given** 线索/客户列表（有 Tab 按钮），**When** 查看，**Then** 搜索框与按钮组有 16px 间距。
2. **Given** 发票/任务/拜访列表（有统计卡片），**When** 查看，**Then** 搜索框与卡片有 16px 间距。
3. **Given** 无顶部内容的列表页（如合同/联系人），**When** 查看，**Then** 搜索框在顶部无多余间距。

### 实现细节

- 7 个文件添加 `<div style={{ height: 16 }} />` 间距：`LeadListPage`、`CustomerListPage`、`InvoiceListPage`、`TaskListPage`、`WorkflowLogListPage`、`SlaPolicyListPage`、`VisitListPage`。
- 全局 CSS `index.css`：`.ant-row .ant-col .ant-form-item { margin-bottom: 24px !important; }` 兜底。
- 全局 CSS `index.css`：`.pro-card .ant-pro-search-form { margin-top: 16px !important; }` 兜底。
- 其余 19 个 ListPage 的 ProTable 是页面第一个元素，无需间距。

### 边界情况

- 预测去重对 CLOSED_LOST 过滤后仍按阶段唯一（前端兜底 + 后端聚合双保险）。
- 布局优化不改业务逻辑；移动端保持横向菜单。
- 客户列表完整显示后，导出路径仍对非管理员脱敏（063 保留）。
