# Feature Specification: 员工使用地图

**Feature Branch**: `029-usage-map`

**Created**: 2026-08-23

**Status**: Draft

**Input**: User description: "员工使用地图：AntV G6 流程图可视化员工在系统中的操作路径（业务主流程+角色操作链+高频入口），首页欢迎区卡片入口"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 业务主流程地图 (Priority: P1)

首页欢迎区提供"员工使用地图"入口，打开后以流程图展示销售全链路（线索→客户→商机→报价→合同→订单回款→客户服务），每个节点含名称/操作要点/页面入口，点击节点跳转对应模块。

**Why this priority**: 新员工或跨角色员工需要快速理解系统业务全貌；流程图比文字菜单更直观，节点可跳转直接上手。

**Independent Test**: 可独立验证——打开使用地图，主流程 7 个节点按序排列，点击"客户"节点跳转客户列表。

**Acceptance Scenarios**:

1. **Given** 首页欢迎区有"查看使用地图"入口，**When** 点击，**Then** 打开使用地图页。
2. **Given** 使用地图主流程视图，**When** 查看，**Then** 显示线索→客户→商机→报价→合同→订单→客户服务 7 节点流程。
3. **Given** 流程图某节点，**When** 点击，**Then** 跳转到对应模块列表页。

### User Story 2 - 角色操作链地图 (Priority: P2)

支持按角色（销售/客服/管理员/全部）切换流程图，展示各角色核心操作链；角色可见性联动 028 角色权限（用户角色无权查看的流程不显示或提示）。

**Why this priority**: 不同角色关注不同操作链，按角色过滤让地图精准对应员工日常工作。

**Independent Test**: 可独立验证——切换到"客服"角色，流程图显示工单接收→处理→回复→关闭→知识库；"销售"角色显示线索→跟进→商机→成交。

**Acceptance Scenarios**:

1. **Given** 使用地图有角色切换（全部/销售/客服/管理员），**When** 选择"客服"，**Then** 流程图切换为客服操作链。
2. **Given** 当前用户角色为客服，**When** 打开地图，**Then** 默认显示客服操作链（优先当前角色）。
3. **Given** 角色切换，**When** 查看节点，**Then** 节点入口仍可跳转对应页面。

### User Story 3 - 高频操作快捷入口 (Priority: P2)

地图底部提供高频操作快捷入口（创建客户/记跟进/新增商机/新建工单/创建任务/新建报价），一键直达对应创建页或列表页。

**Why this priority**: 高频动作一键触达，减少导航层级，提升日常操作效率。

**Independent Test**: 可独立验证——点击"记跟进"快捷入口，跳转客户列表（或跟进入口）。

**Acceptance Scenarios**:

1. **Given** 使用地图底部有高频操作按钮组，**When** 点击"创建客户"，**Then** 跳转客户列表页（打开新增弹窗入口）。
2. **Given** 高频入口按钮，**When** 点击，**Then** 均跳转到对应页面。

### Edge Cases

- G6 未加载/渲染失败：显示降级提示（"地图渲染失败，请刷新"），不影响其他功能。
- 角色流程与用户权限不一致：节点跳转仍受后端权限控制（403 兜底）。
- 移动端：G6 画布可缩放/拖拽，或显示节点列表降级。
- 节点无入口页面（如概念节点）：点击无跳转仅展示说明。
- 首页入口卡片在移动端隐藏或缩小。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须提供"员工使用地图"页面，首页欢迎区提供入口卡片。
- **FR-002**: 使用地图必须展示业务主流程图（线索→客户→商机→报价→合同→订单回款→客户服务），节点含名称/操作要点/页面入口。
- **FR-003**: 使用地图必须支持角色切换（全部/销售/客服/管理员），展示各角色核心操作链。
- **FR-004**: 使用地图节点必须可点击跳转对应模块页（无入口节点仅展示说明）。
- **FR-005**: 使用地图底部必须提供高频操作快捷入口（创建客户/记跟进/新增商机/新建工单/创建任务/新建报价）。
- **FR-006**: 流程图必须用 AntV G6 渲染，支持拖拽/缩放（大图导航）。
- **FR-007**: G6 渲染失败时显示降级提示，不影响页面其他内容。
- **FR-008**: 角色流程可见性联动 028 角色权限（按 user.menus 过滤或角色匹配）。

### Key Entities

- **流程定义（FlowDef）**: { id, title, role?, nodes: [{ id, title, desc, path?, color? }], edges: [{ source, target }] }（前端常量 types/usageMap.ts）。
- **高频操作定义（QuickAction）**: { key, label, icon, path }。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 主流程节点数与定义一致（7 节点），点击跳转正确率 100%（抽查 7 个节点）。
- **SC-002**: 角色切换正确率 100%——4 种视图切换后节点与定义一致（抽查 10 次）。
- **SC-003**: 高频入口跳转正确率 100%（抽查 6 个入口）。
- **SC-004**: G6 渲染无报错（页面无 JS 错误，抽查 5 次加载）。
- **SC-005**: 无回归——首页 DashboardPage 测试不破坏、既有功能正常。

## Assumptions

- 使用 AntV G6 v5（@antv/g6），前端新增依赖。
- 流程定义为前端常量（不引后端配置，减少耦合；后续可配置化）。
- 角色切换为前端过滤（4 种视图），与 028 角色权限联动（当前用户默认视图）。
- 首页入口卡片放 DashboardPage 欢迎区（user.menus 过滤不影响——所有登录用户可见）。
- 移动端 G6 画布支持拖拽缩放（G6 内置），不单独做节点列表降级（可选）。
