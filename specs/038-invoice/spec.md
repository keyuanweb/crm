# Feature Specification: 发票管理

**Feature Branch**: `038-invoice`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P1：订单开票与发票状态跟踪（业界 Zoho/Salesforce 标配；当前订单到回款止，无发票维度）。

## User Stories

### US1 - 开票管理 (P1)
订单详情支持开票：填开票信息（抬头/税号/金额/类型 增值税普票/专票）→ 生成发票记录（编号规则、状态 待开/已开/已作废）；发票关联订单与回款。

**验收**: 订单 A 开"增值税专票"金额 1 万 → 发票记录生成（编号 INV-xxxx）→ 状态"已开"。

### US2 - 发票状态跟踪 (P1)
发票列表（按订单/客户/状态筛选）；状态流转：待开 → 已开 → 已作废（作废需原因 + 审计）；开票率统计（已开金额/订单金额）。

**验收**: 发票列表筛选"已开" → 显示对应记录 → 作废并填原因 → 状态更新 + 审计。

## Requirements

- **FR-001**: 开票：订单详情创建发票（抬头/税号/金额 ≤ 订单剩余可开额/类型/备注），编号自动生成（INV-年月-序号）。
- **FR-002**: 发票状态：DRAFT(待开)/ISSUED(已开)/VOID(已作废)；作废需原因 + 审计。
- **FR-003**: 发票列表：按订单/客户/状态/日期筛选；与订单回款关联展示。
- **FR-004**: 可开金额校验：累计开票 ≤ 订单金额；发票金额 ≤ 剩余可开。
- **FR-005**: 开票统计：客户/订单维度开票率（已开/应收）。
- **FR-006**: 权限：开票/作废为财务或管理员权限（invoice:manage）。

## Success Criteria

- SC-001: 开票创建正确率 100%——编号/金额/类型准确（抽查 5 次）。
- SC-002: 金额校验正确率 100%——超可开额被拒（抽查 5 次）。
- SC-003: 状态流转正确率 100%——作废更新 + 审计（抽查 5 次）。
- SC-004: 开票率统计正确率 100%（抽查 5 次）。

## Edge Cases

- 订单金额变更后已开票：超开校验提示（先作废再改）。
- 发票作废后可重开：释放可开额度。
- 发票删除：仅作废（不物理删）。
- 编号并发：序号用数据库序列/乐观锁。

## Assumptions

- 发票表 invoice（订单外键 + 开票信息 + 状态）；编号 INV-{yyyyMM}-{seq}。
- 不接税控/电子发票平台（预留编号与抬头字段，后续可集成）。
- 与 013 回款独立（发票 ≠ 回款，分开管理但订单页关联展示）。
