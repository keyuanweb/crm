# 研究：发票管理

## R1 开票

**决策**: InvoiceService.create：校验订单存在 + 金额 > 0 + 金额 ≤ 订单剩余可开额（订单金额 - 已开未作废发票金额）。编号 INV-{yyyyMM}-{seq}（当日最大 seq + 1）。

## R2 状态机

**决策**: DRAFT(待开) → ISSUED(已开) → VOID(已作废)。创建即 ISSUED（简化：开票即已开）；作废需原因（必填）+ 审计 + 释放可开额。发票不物理删除（仅作废）。

## R3 统计

**决策**: 按订单：已开金额（非作废）/订单金额 → 开票率；汇总总开票金额/总订单金额/开票率。列表支持订单/客户/状态/日期筛选。

## R4 前端

**决策**: 交易分组加"发票"页：统计卡（总开票率/已开金额/待开）+ 列表（筛选 + 开票弹窗（订单选择 + 抬头/税号/金额/类型）+ 作废弹窗（原因））；订单详情页加"开票"入口（跳发票页带订单参数）。
