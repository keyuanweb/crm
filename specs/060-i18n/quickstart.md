# Quickstart: 国际化（i18n）模块验证指南

**Branch**: `060-i18n`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）。
- 本模块纯前端，无后端/迁移变更。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过。

### 2. 手动验证（语言切换）

1. 登录系统，顶栏/设置中切换语言为 English。
2. **预期**：系统名、左侧菜单（分组与项）、顶栏文案立即变英文；首页问候变英文。
3. 刷新页面。
4. **预期**：语言偏好保持 English。

### 3. 手动验证（回退）

- 切换英文后，若某 key 未翻译，**预期**：显示中文（fallback），不白屏。

### 4. 契约核对

- 无后端接口变更；仅前端文案资源化。
