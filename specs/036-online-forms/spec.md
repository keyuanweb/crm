# Feature Specification: 在线表单线索收集

**Feature Branch**: `036-online-forms`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P1：官网/落地页在线表单自动收集线索进线索池（业界 HubSpot/Marketo 标配）。

## User Stories

### US1 - 表单配置 (P1)
管理员创建表单（字段：姓名/公司/电话/邮箱/留言等，可配必填 + 自定义字段），生成外链/嵌入代码；表单可关联来源（渠道归因）。

**验收**: 创建"产品试用申请"表单 → 生成链接 → 预览表单 → 配置来源"官网"。

### US2 - 线索自动收集 (P1)
访客提交表单 → 自动创建线索（来源=表单来源，状态=NEW，进线索池）+ 可配邮件通知销售（030 联动）；提交记录（防重复：邮箱/手机查重）。

**验收**: 提交表单 → 线索池出现新线索（来源官网）→ 重复邮箱提交被拦截提示。

## Requirements

- **FR-001**: 表单 CRUD：字段配置（内置字段 + 自定义字段 + 必填校验）、成功提示语、来源绑定。
- **FR-002**: 表单发布：外链 URL + 内嵌代码（script）；匿名可提交（无需登录，公开端点）。
- **FR-003**: 提交入库：自动创建线索（姓名/公司/电话/邮箱 → lead），来源 = 表单来源，状态 NEW；数据权限默认进池。
- **FR-004**: 防重复：邮箱或手机已存在线索时提示"已收到申请"不重复建。
- **FR-005**: 提交记录：form_submission 表（字段快照 + 时间 + IP）；可查看。
- **FR-006**: 可选通知：新提交推送通知（026）/邮件（030）。
- **FR-007**: 权限：表单配置为营销管理权限（form:manage）；提交端点公开（仅限表单字段，防注入）。

## Success Criteria

- SC-001: 表单 CRUD + 发布正确率 100%（抽查 5 次）。
- SC-002: 提交建线索正确率 100%——字段映射准确（抽查 10 提交）。
- SC-003: 防重复拦截正确率 100%（抽查 5 次）。
- SC-004: 提交端点匿名可用且安全（XSS/注入防护抽查 5 次）。

## Edge Cases

- 表单字段恶意内容：服务端校验长度/白名单。
- 高频提交：限流（IP + 时间窗口）。
- 自定义字段值非法枚举：忽略或默认。
- 表单停用：外链返回"表单已关闭"。

## Assumptions

- 公开提交端点（POST /api/v1/public/forms/{id}/submit）无需 JWT（防爬用轻量校验 + 频控）。
- 字段映射到 lead（+自定义字段表）；留言存 lead.remark。
- 表单表 form + 提交表 form_submission；来源复用现有 lead.source（表单来源映射 WEBSITE/OTHER）。
