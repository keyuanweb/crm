# 实施计划：酷炫数据大屏（Data Vision）

**功能分支**: `071-data-vision`

**创建日期**: 2026-08-29

## 实施概述

本计划旨在重新设计现有 KpiBoardPage 数据大屏，实现酷炫的视觉效果和全屏展示功能。完全复用现有 KPI 大屏 API（`/api/v1/kpi-board`），不修改后端代码，所有改动在前端实现。

## 技术架构

### 前端技术栈

- **React 18.2.0**: 组件库
- **TypeScript 5.x**: 类型安全
- **Ant Design 5.22.0**: UI 组件库
- **ECharts 5.x**: 图表库（新增依赖）
- **Canvas API**: 粒子动画背景
- **CSS Animation**: 流光边框、霓虹文字效果
- **Fullscreen API**: 全屏切换
- **React Query**: 数据缓存和刷新

### 后端技术栈

- **无改动**: 完全复用现有 KPI 大屏 API（`/api/v1/kpi-board`）

## 风险与缓解

### 风险 1: ECharts 包体积过大

**影响**: 页面加载时间可能超过 3 秒。

**缓解**:
- 使用代码分割（React.lazy + Suspense）
- 使用 dynamic import() 动态导入 ECharts
- 使用 webpack 代码分割，将 ECharts 单独打包

### 风险 2: 粒子动画性能问题

**影响**: 帧率可能低于 30 FPS。

**缓解**:
- 使用 requestAnimationFrame 实现动画循环
- 限制粒子数量（根据屏幕分辨率动态调整）
- 使用 will-change: transform 提示浏览器优化
- 使用 OffscreenCanvas（如果支持）

### 风险 3: Fullscreen API 兼容性问题

**影响**: 某些浏览器可能不支持 Fullscreen API。

**缓解**:
- 使用特性检测（document.fullscreenEnabled）
- 降级策略：使用 CSS 100vh/100vw 实现全屏布局
- 提供手动全屏按钮作为备选
