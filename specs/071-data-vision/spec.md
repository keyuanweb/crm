# 功能规格：酷炫数据大屏（Data Vision）

**功能分支**: `071-data-vision`

**创建日期**: 2026-08-29

**状态**: 草稿

**输入**: 现有 KpiBoardPage 数据大屏功能基础，需要重新设计为酷炫风格，支持全屏（占满电脑屏幕所有页面）展示，按照 SDD 规范实现。

## 用户场景与测试（必填）

### 用户故事 1 - 酷炫全屏数据大屏展示（优先级：P0）

管理员或销售负责人打开数据大屏页面，看到酷炫的深色主题界面，包含动态粒子背景、流光边框效果、霓虹文字标题。大屏自动占满整个浏览器窗口（使用全屏 API），隐藏所有导航栏、侧边栏、页眉页脚，只保留数据可视化内容。数据每 30 秒自动刷新，支持手动刷新和退出全屏。

**优先级理由**: 核心需求，直接回答"如何展示酷炫的全屏数据大屏"。

**独立测试**: 打开大屏页面 → 验证深色主题、粒子背景、流光边框 → 点击全屏按钮 → 验证占满整个屏幕 → 验证数据自动刷新 → 验证退出全屏。

**验收场景**:

1. **Given** 用户访问数据大屏页面，**When** 页面加载完成，**Then** 展示深色主题、粒子动画背景、流光边框面板、霓虹文字标题。
2. **Given** 用户点击"全屏"按钮，**When** 全屏 API 调用成功，**Then** 页面占满整个浏览器窗口，隐藏所有导航元素，数据可视化内容自适应布局。
3. **Given** 大屏处于全屏状态，**When** 30 秒后，**Then** 数据自动刷新，数值平滑过渡动画更新。
4. **Given** 用户按 ESC 或点击"退出全屏"按钮，**When** 退出全屏，**Then** 恢复常规布局，显示导航栏和侧边栏。

---

### 用户故事 2 - 核心指标可视化（优先级：P0）

大屏顶部展示核心 KPI 指标卡，包括商机总数、金额合计、赢单率、客户总数、活跃客户、本月新增客户。每个指标卡使用大字体数字、渐变色、动态计数动画，边框带有流光效果。数据变化时数字滚动更新，带有平滑过渡动画。

**优先级理由**: 核心指标是大屏最重要的内容，需要最醒目的展示。

**独立测试**: 造数后打开大屏 → 验证 6 个指标卡数值正确 → 验证数字滚动动画 → 验证流光边框效果。

**验收场景**:

1. **Given** 系统存在商机、客户数据，**When** 打开大屏，**Then** 顶部展示 6 个核心指标卡，数值与明细一致，带有数字滚动动画。
2. **Given** 数据刷新，**When** 数值变化，**Then** 数字从旧值滚动更新到新值，带有平滑过渡动画。
3. **Given** 无任何业务数据，**When** 查看指标卡，**Then** 展示 0 值，不报错。

---

### 用户故事 3 - 动态图表可视化（优先级：P0）

大屏中部展示多个动态图表：
- 销售漏斗图（横向条形图，带渐变填充和流光边框）
- 团队排行 Top10（带排名徽章和进度条）
- 客户健康度分布（环形图/饼图，带脉冲动画）
- 智能建议摘要（卡片式展示，带图标和颜色编码）
- 近 30 天商机金额趋势（折线图/面积图，带渐变填充和动态绘制动画）

**优先级理由**: 图表是大屏的核心可视化内容，需要酷炫的动态效果。

**独立测试**: 造数后打开大屏 → 验证所有图表渲染正确 → 验证动态动画效果 → 验证数据更新平滑过渡。

**验收场景**:

1. **Given** 存在各阶段销售机会数据，**When** 查看漏斗图，**Then** 展示横向条形图，各阶段数量/金额正确，带有渐变填充。
2. **Given** 存在团队成员业绩数据，**When** 查看团队排行，**Then** 展示 Top10 排名，带排名徽章（金银铜）和进度条。
3. **Given** 存在客户健康度数据，**When** 查看健康度分布，**Then** 展示环形图，红/黄/绿三色比例正确，带有脉冲动画。
4. **Given** 存在趋势数据，**When** 查看趋势图，**Then** 展示折线图/面积图，带有渐变填充和动态绘制动画。
5. **Given** 图表数据更新，**When** 刷新，**Then** 图表平滑过渡到新状态，不闪烁。

---

### 用户故事 4 - 响应式布局与自适应（优先级：P1）

大屏在不同分辨率的显示器上自动调整布局：
- 1920×1080（标准桌面）：3 列布局，每列等宽
- 2560×1440（高分辨率）：4 列布局，增加图表宽度
- 3840×2160（4K）：5 列布局，增大字体和图表尺寸
- 全屏模式下自动适配浏览器窗口大小

**优先级理由**: 确保大屏在各种显示设备上都有良好的展示效果。

**独立测试**: 在不同分辨率下打开大屏 → 验证布局自动调整 → 验证字体和图表尺寸自适应。

**验收场景**:

1. **Given** 用户在 1920×1080 显示器上，**When** 打开大屏，**Then** 展示 3 列布局，字体和图表尺寸适中。
2. **Given** 用户在 2560×1440 显示器上，**When** 打开大屏，**Then** 展示 4 列布局，图表宽度增加。
3. **Given** 用户在 3840×2160 显示器上，**When** 打开大屏，**Then** 展示 5 列布局，字体和图表尺寸增大。
4. **Given** 用户调整浏览器窗口大小，**When** 窗口大小变化，**Then** 布局自动调整，图表重新绘制。

---

### 边界情况

- 无任何业务数据时，各图表展示 0 或空状态，不报错，保持酷炫视觉效果。
- 网络请求失败时，展示错误提示，保留上次成功数据，不中断全屏状态。
- 全屏 API 不可用时（如某些浏览器），降级为常规全屏布局（占满容器），不报错。
- 数据刷新失败时，保留上次数据，显示错误提示，不刷新数值动画。
- 长时间停留（超过 30 分钟），自动刷新数据，保持数据新鲜度。
- 多标签页同时打开大屏时，每个标签页独立刷新，不互相影响。

## 需求（必填）

### 功能需求

#### 酷炫数据大屏模块

- **FR-DV01**: 系统必须提供酷炫的深色主题数据大屏界面，包含粒子动画背景、流光边框效果、霓虹文字标题。
- **FR-DV02**: 系统必须支持全屏展示（使用 Fullscreen API），占满整个浏览器窗口，隐藏所有导航元素。
- **FR-DV03**: 系统必须展示 6 个核心 KPI 指标卡（商机总数、金额合计、赢单率、客户总数、活跃客户、本月新增客户），带有数字滚动动画和流光边框。
- **FR-DV04**: 系统必须展示销售漏斗图（横向条形图，带渐变填充和流光边框）。
- **FR-DV05**: 系统必须展示团队排行 Top10（带排名徽章和进度条）。
- **FR-DV06**: 系统必须展示客户健康度分布（环形图/饼图，带脉冲动画）。
- **FR-DV07**: 系统必须展示智能建议摘要（卡片式展示，带图标和颜色编码）。
- **FR-DV08**: 系统必须展示近 30 天商机金额趋势（折线图/面积图，带渐变填充和动态绘制动画）。
- **FR-DV09**: 系统必须支持数据自动刷新（默认 30 秒间隔），支持手动刷新。
- **FR-DV10**: 系统必须支持响应式布局，根据屏幕分辨率自动调整列数（3/4/5 列）和字体大小。
- **FR-DV11**: 系统必须提供全屏切换按钮和 ESC 键退出全屏支持。
- **FR-DV12**: 系统必须使用 ECharts 5.x 作为图表库，支持动态动画效果。

#### 权限与约束

- **FR-DV13**: 系统必须对大屏聚合数据做缓存（最多 5 分钟），业务数据写操作后失效缓存。
- **FR-DV14**: 系统必须确保大屏页面仅展示未删除数据（逻辑删除的客户/商机/机会不计入）。
- **FR-DV15**: 系统必须确保大屏页面需要用户登录认证，未登录用户重定向到登录页。
- **FR-DV16**: 系统必须确保大屏页面的数据权限与用户角色一致（ADMIN 查看全部，SELF 查看本人，DEPT 查看本部门）。

### 非功能需求

- **NFR-DV01**: 大屏页面加载时间不超过 3 秒（首次加载）。
- **NFR-DV02**: 数据刷新响应时间不超过 2 秒。
- **NFR-DV03**: 全屏模式下帧率不低于 30 FPS（粒子动画和图表动画）。
- **NFR-DV04**: 大屏页面代码大小不超过 200KB（gzip 后）。
- **NFR-DV05**: 大屏页面必须兼容 Chrome 90+、Edge 90+、Firefox 88+、Safari 14+。

## 数据模型（必填）

### 现有数据复用

- **KpiBoard**: 复用现有 KPI 大屏 API 数据（`/api/v1/kpi-board`），包含：
  - `kpi`: 核心指标（opportunityCount, amountTotal, winRate, customerCount, activeCustomerCount, newCustomersThisMonth）
  - `funnel.stages`: 销售漏斗各阶段（stage, count, amountTotal, conversionRate）
  - `leaderboard`: 团队排行（userId, displayName, wonAmount, achievementRate）
  - `healthDistribution`: 客户健康度分布（red, yellow, green）
  - `suggestions`: 智能建议摘要（atRiskCustomers, stalledOpportunities, followUpCustomers, highScoreLeads）
  - `trend`: 近 30 天趋势（date, amount）

### 新增数据模型

- 无新增数据模型，完全复用现有 KPI 大屏 API。

## 用户界面（必填）

### 页面布局

- **顶部区域**（10% 高度）: 标题栏，包含霓虹文字标题、实时时钟、全屏切换按钮、手动刷新按钮。
- **KPI 指标卡区域**（15% 高度）: 6 个核心指标卡，横向排列，带有数字滚动动画和流光边框。
- **图表区域**（60% 高度）: 分为 3 列（或 4/5 列，根据分辨率），包含销售漏斗、团队排行、客户健康度、智能建议、趋势图。
- **底部区域**（15% 高度）: 数据更新时间、刷新状态、技术支持信息。

### 视觉设计

- **主题**: 深色主题，背景色 `#0a1830`，主色调 `#4da3ff`（蓝色），辅助色 `#52c41a`（绿色）、`#fa8c16`（橙色）、`#ff4d4f`（红色）。
- **背景**: 粒子动画背景（使用 canvas 实现），粒子颜色为半透明蓝色，带有连线效果。
- **边框**: 流光边框效果（使用 CSS animation 实现），边框颜色为蓝色渐变，带有流光动画。
- **文字**: 霓虹文字效果（使用 text-shadow 实现），标题颜色为蓝色渐变，带有发光效果。
- **图表**: 使用 ECharts 5.x，主题色为深色，带有动态动画效果。
- **动画**: 数字滚动动画（使用 count-up 动画）、图表动态绘制动画、粒子动画、流光边框动画。

### 交互设计

- **全屏切换**: 点击全屏按钮或按 F11 键进入全屏，按 ESC 键退出全屏。
- **手动刷新**: 点击刷新按钮手动刷新数据，带有旋转动画。
- **数据更新**: 数据刷新时，数值平滑过渡动画更新，不闪烁。
- **鼠标悬停**: 鼠标悬停在指标卡或图表上时，显示详细信息 tooltip。

## 技术选型（必填）

### 前端技术栈

- **React 18.2.0**: 组件库。
- **TypeScript 5.x**: 类型安全。
- **Ant Design 5.22.0**: UI 组件库（Button, Tag, Typography 等）。
- **ECharts 5.x**: 图表库（折线图、条形图、饼图、环形图）。

- **Spring Boot 3.2.0**: 后端框架。
- **MyBatis-Plus 3.5.5**: ORM 框架。
- **Redis**: 数据缓存（可选，已有）。
