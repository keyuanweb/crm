# 功能规格：更多页面国际化（i18n Pages）模块

**功能分支**: `066-i18n-pages`

**创建日期**: 2026-08-26

**状态**: 草稿

**输入**: 审计发现前端 2049 处硬编码中文 vs 133 处 t()——i18n 仅覆盖核心框架（菜单/登录/首页），业务页面大量中文硬编码。本模块按 SDD 流程将主要业务页面的用户可见文案替换为 i18n key，支持中英文切换。

## 用户场景与测试（必填）

### 用户故事 1 - 客户管理页面国际化（优先级：P0）

客户列表/详情/编辑的所有用户可见文案（列标题、按钮、表单标签、占位符、消息提示、状态文本）支持中英文切换。

**优先级理由**: 客户是 CRM 核心实体，使用频率最高，i18n 收益最大。

**独立测试**: 切换到 English → 客户列表页所有文案变为英文。

**验收场景**:

1. **Given** 客户列表页，**When** 切换语言为 English，**Then** 所有列标题/按钮/消息提示变为英文。
2. **Given** 客户详情页，**When** 切换语言，**Then** 基本信息标签/操作按钮变为英文。
3. **Given** 编辑客户 Modal，**When** 切换语言，**Then** 表单标签/验证消息变为英文。

---

### 用户故事 2 - 产品/商机/合同页面国际化（优先级：P0）

产品目录、商机列表/详情、合同列表/详情的用户可见文案支持中英文切换。

**优先级理由**: 销售链路核心页面，与 001-007 直接相关。

**独立测试**: 切换到 English → 各页面文案正确翻译。

**验收场景**:

1. **Given** 产品列表页，**When** 切换语言，**Then** 列标题/按钮/状态变为英文。
2. **Given** 商机列表页，**When** 切换语言，**Then** 阶段标签/金额格式化说明变为英文。
3. **Given** 合同列表页，**When** 切换语言，**Then** 状态/操作按钮变为英文。

---

### 用户故事 3 - 工单/线索/联系人页面国际化（优先级：P1）

工单列表/详情、线索列表/详情、联系人列表的用户可见文案支持中英文切换。

**优先级理由**: 服务协作和基础数据管理页面。

**验收场景**:

1. **Given** 工单列表页，**When** 切换语言，**Then** 优先级/状态/Sla 标签变为英文。
2. **Given** 线索列表页，**When** 切换语言，**Then** 列标题/认领按钮变为英文。
3. **Given** 联系人列表页，**When** 切换语言，**Then** 列标题/共享按钮变为英文。

### 边界情况

- 已国际化的资源（菜单/登录/首页问候）不重复定义。
- 数字/金额格式不翻译（toLocaleString 行为由浏览器决定）。
- 错误码（ErrorCode）保持英文 code + 中文 message（后端返回），前端统一映射。
- 新增 i18n key 不破坏现有中文界面（默认 zh-CN fallback）。

## 需求（必填）

### 功能需求

#### 页面覆盖

- **FR-P01**: 客户管理（列表/详情/编辑）所有用户可见文案必须 i18n key 化。
- **FR-P02**: 产品目录（列表/编辑）所有用户可见文案必须 i18n key 化。
- **FR-P03**: 商机管理（列表/详情）所有用户可见文案必须 i18n key 化。
- **FR-P04**: 合同管理（列表/详情）所有用户可见文案必须 i18n key 化。
- **FR-P05**: 工单管理（列表/详情）所有用户可见文案必须 i18n key 化。
- **FR-P06**: 线索管理（列表/详情）所有用户可见文案必须 i18n key 化。
- **FR-P07**: 联系人管理（列表）所有用户可见文案必须 i18n key 化。
- **FR-P08**: 任务/审批/公告等常用页面覆盖。

#### 资源组织

- **FR-P09**: 每个页面一个命名空间（如 `customer.list`、`product.edit`），避免单文件过大。
- **FR-P10**: 通用文案提取到公共命名空间（如 `common.button`、`common.status`）。

### 权限与约束

- **FR-P11**: 不改变现有中文界面行为（默认 zh-CN）。
- **FR-P12**: 不引入新的运行时依赖（复用 react-i18next）。

### 关键实体（涉及数据）

- 无新增表；纯前端文案迁移。

## 成功标准（必填）

### 可度量结果

- **SC-P01**: 覆盖 7+ 个核心页面（客户/产品/商机/合同/工单/线索/联系人）。
- **SC-P02**: 切换语言后无中文残留（抽查每页 10 处文案）。
- **SC-P03**: typecheck / lint / build 通过。
- **SC-P04**: 不影响现有中文界面（回归验证）。

## 假设

- 每个页面先做最小可行集（列标题 + 按钮 + 表单标签 + 消息提示），后续逐步补充。
- 金额格式化（toLocaleString）不翻译——这是正确的（浏览器 locale 自动处理）。

## 依赖
