# Quickstart: 更多页面国际化模块验证指南

**Branch**: `066-i18n-pages`

## 前置条件

- 前端 dev 运行（5173）。
- 无后端变更。

## 验证场景

### 1. 语言切换验证

1. 打开任意核心页面（客户列表/产品目录等）。
2. 点击顶栏语言切换为 English。
3. **预期**：所有列标题、按钮、表单标签、消息提示变为英文，无中文残留。
4. 切换回中文。**预期**：文案恢复中文。

### 2. 抽查清单（每页至少 10 处）

| 页面 | 抽查项 |
|---|---|
| 客户列表 | 列标题(6)、按钮(3)、消息(1) |
| 产品列表 | 列标题(6)、按钮(3)、消息(1) |
| 商机列表 | 阶段标签(6)、列标题(3)、金额说明(1) |
| 合同列表 | 状态文本(6)、列标题(3)、操作按钮(2) |
| 工单列表 | 优先级/Sla 标签(5)、列标题(4)、消息(1) |
| 线索列表 | 列标题(5)、认领按钮(1)、消息(1) |
| 联系人列表 | 列标题(5)、共享按钮(1)、消息(1) |

### 3. 契约核对

- 资源文件对照 `resources/*.json`。
- 命名规范：`page.section.field`。
