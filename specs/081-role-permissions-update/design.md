# 角色权限更新设计文档

> 基于当前菜单和功能模块，更新角色权限配置，符合 SDD 规范。

## 一、角色定义

### 1.1 系统预置角色

| 角色编码 | 角色名称 | 描述 | 数据范围 |
|---------|---------|------|---------|
| ADMIN | 系统管理员 | 拥有所有权限，包括系统配置和用户管理 | ALL |
| SALES_MANAGER | 销售总监 | 销售团队管理者，查看团队数据 | DEPT |
| SALES_REP | 销售代表 | 一线销售人员，管理自己的客户和商机 | SELF |
| SUPPORT_MANAGER | 客服主管 | 客服团队管理者 | DEPT |
| SUPPORT_AGENT | 客服专员 | 一线客服人员，处理工单和咨询 | SELF |
| MARKETING_MANAGER | 市场总监 | 市场团队管理者 | DEPT |
| MARKETING_SPECIALIST | 市场专员 | 市场活动执行者 | SELF |
| FINANCE_MANAGER | 财务总监 | 财务相关功能管理者 | DEPT |
| FINANCE_ACCOUNTANT | 财务专员 | 财务相关操作者 | SELF |
| ANALYST | 数据分析师 | 数据查看和报表分析 | ALL |
| VIEWER | 只读用户 | 仅查看权限，无编辑权限 | SELF |

### 1.2 角色数据范围说明

- **ALL**: 查看所有数据
- **DEPT**: 查看本部门及下级部门数据
- **SELF**: 仅查看自己创建的数据
