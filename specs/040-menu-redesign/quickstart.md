# Quickstart: 菜单分类重设计模块验证指南

**Branch**: `040-menu-redesign`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）；后端运行于 8081。
- 本模块无后端/迁移变更，无需重启后端。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过。

### 2. 手动验证（分组结构）

1. 以 admin 登录，查看左侧菜单。
2. **预期**：首页（置顶）+ 8 个分组：客户管理（线索/客户/联系人/查重合并/流失预警）、销售管理（商机/销售机会/报价单/外勤拜访/产品）、交易管理（合同/订单/发票）、营销中心（营销活动/邮件营销/在线表单）、服务协作（客户服务/知识库/公告管理/我的审批）、工作台（任务/智能建议/数据大屏）、数据分析（自定义报表/团队排行/导出中心）、系统管理（配置类全项）。
3. 每组 2~5 项，无过薄/过载分组。

### 3. 手动验证（权限归位）

1. 创建/使用一个菜单权限含 announcements 与 approvals 的非 ADMIN 账号登录。
2. **预期**：服务协作组显示公告管理与我的审批。
3. 管理员登录可见系统管理全部配置项。

### 4. 手动验证（路由可达）

- 每组抽查 1 项点击，目标页面正常渲染、菜单高亮正确。

### 5. 移动端

- 窗口 <768px：菜单拍平为普通项（无分组），全部入口可点。

## 契约核对

- 无后端接口变更，契约无更新。
