# Feature Specification: 客户查重合并

**Feature Branch**: `034-customer-merge`

**Created**: 2026-08-23

**Status**: Draft

**Input**: P0-二批：批量查重 + 合并工具，清理历史重复客户（业界 Salesforce/Zoho 标配）。

## User Stories

### US1 - 查重扫描 (P1)
管理员执行查重扫描：按名称（精确/模糊）+ 公司 + 电话/邮箱相似度规则识别疑似重复对，结果列表展示重复对（主记录 + 重复记录 + 相似度 + 关联数据计数）。

**验收**: 扫描后显示 2 组疑似重复（如"Acm 科技" vs "Acme 科技"），含各自订单/商机/联系人数量。

### US2 - 合并 (P1)
选择主记录 + 从记录 → 合并：从记录关联数据（订单/商机/联系人/跟进/工单）转移归属主记录，字段冲突选优（主记录优先或手动选），从记录删除（进回收站可恢复）。

**验收**: 合并后主记录关联订单/联系人数量 = 两者之和；从记录进回收站。

## Requirements

- **FR-001**: 查重规则配置：匹配字段（名称/公司/电话/邮箱）、阈值（精确/模糊）、扫描范围（全部/筛选）。
- **FR-002**: 查重扫描：批量比对生成疑似重复对，结果含相似度与关联计数。
- **FR-003**: 合并：选主/从记录 → 关联数据转移（订单/商机/联系人/跟进/工单/标签/共享）→ 字段冲突策略（主优先/手动选择）→ 从记录逻辑删除进回收站。
- **FR-004**: 合并审计：记录合并操作（谁/何时/主从记录/转移数量）。
- **FR-005**: 权限：查重合并为管理员权限（customer:merge 或复用 customer:manage）。

## Success Criteria

- SC-001: 查重扫描正确率 100%——已知重复对被检出（抽查 5 组）。
- SC-002: 合并数据转移正确率 100%——关联数据计数核验（抽查 5 次）。
- SC-003: 合并后从记录不可见、主记录完整（抽查 5 次）。
- SC-004: 回收站可见被合并的从记录（可恢复）。

## Edge Cases

- 合并时主/从记录同时被修改：乐观锁冲突提示重试。
- 从记录已有重名联系人/商机：追加或跳过（记录）。
- 合并后唯一性冲突（客户名称）：主记录名保留、提示。
- 大范围扫描性能：分批执行（LIMIT 500/批）。

## Assumptions

- 查重用 SQL LIKE + 归一化（去空格/大小写/全半角）+ 电话精确匹配，不引模糊匹配库。
- 合并事务内完成（转移 + 删除 + 审计）。
- 回收站已支持客户恢复（025），合并删除复用。
