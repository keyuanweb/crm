## 二、差距分析（对标成熟 CRM）

按"成熟 CRM 必备"逐项对照，标记差距等级：🟢已有 / 🟡部分 / 🔴缺失。

### 1. 销售云（Sales Cloud）
| 能力 | 状态 | 说明 |
|---|---|---|
| 线索/客户/联系人/商机 | 🟢 | 完整 |
| 报价/合同/订单/回款/发票 | 🟢 | 完整 |
| **销售漏斗/预测** | 🟢 | 006/023 有基础 |
| **销售流程 Playbook / 销售方法（阶段自定义+引导动作）** | 🔴 | 商机阶段固定 4 个，无阶段自定义与动作引导 |
| **竞品管理 / 价格表多币种** | 🔴 | 产品单币种、无竞品对比 |
| **销售配额分解（按人/团队/季度）** | 🟡 | 020 有月度目标，无团队/季度维度 |
| **电话集成 CTI / 通话记录** | 🔴 | 无呼叫中心/通话记录 |
| **邮件同步（Outlook/Gmail 双向）** | 🔴 | 无 |
| **报价电子签署（e-signature）** | 🔴 | 报价 PDF 手动签署 |
| **促销/折扣审批** | 🟡 | 报价审批单级，无促销规则 |

### 2. 营销云（Marketing Cloud）
| 能力 | 状态 | 说明 |
|---|---|---|

| **邮件模板可视化编辑器** | 🟡 | 模板有，无拖拽式编辑 |
| **A/B 测试 / 送达率/退订管理** | 🔴 | 无 |
| **着陆页（托管）与 UTM 跟踪** | 🟡 | 表单有，无托管落地页/UTM |
| **线索培育（评分+自动流转）** | 🟡 | 019 评分有，无自动培育流程 |

## 三、建议补齐功能（按优先级）

### P0：销售闭环增强（直接影响成交）
| 建议模块 | 内容 | 依赖 |
|---|---|---|
| 043-sales-playbook | 商机阶段自定义 + 每阶段动作引导（待办/模板/话术） | 商机(001)、任务(010) |
| 044-contract-renewal | 合同到期续约提醒 + 续约漏斗视图 | 合同(008)、通知(026) |
| 045-e-signature | 报价/合同在线签署（手写/图片签名 + 签署记录） | 报价(007)、合同(008) |

### P1：营销自动化（获客转化提升）
| 建议模块 | 内容 | 依赖 |
|---|---|---|
| 046-marketing-automation | 客户旅程编排（触发器→条件→动作，如"填表后 24h 发欢迎邮件+建任务"） | 邮件(030)、标签(031)、评分(019) |
| 047-email-advanced | 退订管理、送达率统计、A/B 测试、可视化模板 | 邮件(030) |
| 048-landing-page | 托管落地页 + UTM 参数跟踪 + 转化归因 | 表单(036)、营销(014) |

### P1：服务与客户成功
| 建议模块 | 内容 | 依赖 |
|---|---|---|
| 049-customer-portal | 客户自助门户（在线提交工单、查进度、知识库浏览） | 工单(015)、知识库(015) |
| 050-csat-nps | 工单关闭后满意度调查（CSAT）+ NPS 统计 | 工单(015) |
| 051-sla-calendar | SLA 工作时间/节假日日历（计入工单时限） | SLA(015) |

### P2：平台开放（生态与扩展）
| 建议模块 | 内容 | 依赖 |
|---|---|---|
| 052-open-platform | 对外 REST API 管理（API Key/权限/限流）、Webhook 事件订阅 | 全模块 |
| 053-integration-hub | 第三方连接器框架（钉钉/企微/企业微信通知、日历同步） | 通知(026) |
| 054-field-permission | 字段级读写权限（按角色隐藏/只读字段） | 权限(028)、自定义字段(016) |
| 055-multi-currency | 多币种产品价格/汇率/报表折算 | 产品(007) |

### P3：长期增强（可选）
| 建议模块 | 内容 |
|---|---|
| 056-call-center | CTI 电话集成/通话记录（需硬件/运营商对接） |
| 057-email-sync | Outlook/Gmail 邮件双向同步 |
| 058-custom-object | 低代码自定义对象（元数据驱动建模） |
| 059-i18n | 多语言/多时区 |

## 四、实施批次建议

- **批次 1（P0，销售闭环）**：043 销售 Playbook → 044 续约 → 045 电子签署（先做 043/044，价值直接、无外部依赖）
- **批次 2（P1，营销与服务）**：046 营销自动化 → 049 客户门户 → 050 CSAT（营销与服务的体验补齐）
- **批次 3（P1 剩余 + P2 平台）**：047/048 邮件增强与落地页、051 SLA 日历、052 开放平台
- **批次 4（P2/P3）**：053~059 按需（集成、字段权限、多币种、长期项）

## 五、待确认问题（供决策）

1. **范围取舍**：P0 三项（Playbook/续约/签署）是否优先启动？还是有其他业务痛点优先？
2. **集成需求**：是否需要对接钉钉/企微/邮件客户端？如有，明确目标系统（决定 053/057 优先级）。
3. **对外能力**：客户自助门户（049）是否在范围？涉及对外访问与安全策略。
4. **多币种/国际化**：是否有海外业务诉求（决定 055/059）？
