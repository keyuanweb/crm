## 1 为什么是这一批（且为什么它可以很小）

096 交付时把 5 件事**只登记不改**，本项是那 5 件的收口。**立项前逐项实测，三项的射程与登记时不同**：

- ① 从「1 个死码」实测为「**22 个未接线码**」，且**分两种性质**（11 个有操作但由别的码放行 / 11 个全仓无操作）；
- ② 从「注释与台账差 1」定位到**根因**（`Currency` 已修、块头聚合数未回改）；
- ⑤ 从「V72 空缺」连带查出 **§一 有 4 行已被 096 作废**（迁移计数漏改的第 6 处）。

**但仍可以很小**，因为①的处置被一条**既有书面裁决**钉死了方向
（`RequirePermissionCatalogTest` 类注释：「反向（字典里有、注解没用）**刻意不断言**……未使用是常态」）：
⇒ **不删、不接线、不动授权语义**，只做「**存量登记成可核事实 + 只对新增设护栏**」。
这与 096 的非目标 4（「只建被端点真引用的码」）**射程不同、不冲突**——那条管新增，这条管存量。

## 2 结构决策

**产出 `research.md`，不产出 `data-model.md` 与 `contracts/`**：
本项**无新实体、无新字段、无迁移**（一行 SQL 都不加），**无 DTO/端点结构变更**。
为凑齐工件而生成空壳文件正是「为了流程而流程」（与 092/095/096 的先例一致）。

**但必须产出 `research.md`**：本项的核心不是过程记录，而是**对 096 那张遗留清单的逐项复核**——
哪一项射程变了、变到多大、依据是什么。这与 096 把「清单逐行复核」当交付物是同一种做法。

**工件产出方式**：**手写**（照 `.specify/templates/` 与 086–096 已入库工件的体例），
**不运行任何 `/speckit-*` 命令**，**不碰 `.specify/feature.json`**（共享单槽指针、gitignored、历史无副本）。

```bash
cd backend  && mvn -B verify
cd frontend && pnpm typecheck && pnpm lint && pnpm i18n:check && pnpm menu:check && pnpm perms:check && pnpm ui:check && pnpm test:coverage
```

- 后端：退出码 0；JaCoCo INSTRUCTION ≥ **0.73**（**阈值不得下调**）；surefire 净增 = 本项新增用例数
  （本项新增 1 个测试类、2 个 `@Test` ⇒ 净增须**对得上**，以「基线 + N」为判据，工区须无第二写入者）。

  `ui:check` 冻结台账**不得增长**（**以实跑读数为准**）。本项**不改前端产品代码**，故前端读数应与 096 交付时一致。

### 4.2 定向破坏（每条声称是护栏的断言都要**被观测到转红**，逐条**逐字节还原**、破坏期间不提交）

| # | 断言 | 破坏 | 期望转红 |
|---|---|---|---|
| D1 | `UnwiredPermissionCodeTest`：台账**不得增长** | 在 `RoleConstants` 字典里新增一个无人用的码（如给某组加 `perm("demo:unused", "…")`） | 该测试，且信息里点名 **`demo:unused`** |
| D2 | 同上：台账**不得减少** | 把白名单里 `system:manage` 一条删掉 | 该测试（少一个 → 台账在骗人） |

D4 是**反向**用法：它证明的不是「我的护栏有牙齿」，而是「另一条路确实走不通」，故它的期望也是**红**。

## 5 风险

| 风险 | 缓解 |
|---|---|
| **把「存量容忍」误读成「应当删码」⇒ 撞 `PermissionMatrixIT`** | 台账护栏**只断言 22 条集合**，不断言「必须为空」；spec §1.2 写清删码的两条硬后果 |
| **把「未使用是常态」当成「不必登记」** | 本项正是要消灭「22 个码无人说过话」这个状态：护栏的**理由字段逐条必填** |
| 台账写成单向（只防增长） | **双向断言**：减少也红——否则接线后忘删白名单，台账会开始骗人 |
| 把 ① 干成一次接线批次（范围爆炸） | spec §4 非目标 1 明写「接线另立」并给出规模理由（等同 096） |
| A 类码被写成「暂无对应操作」= 假话 | spec §4 非目标 2 点名这条陷阱：**A 类有操作**，只是由相邻码放行；本项因此**不动任何 label** |
| 回填 081 时被当成 spec-first | 首段强制声明「事后回填」；偏差表逐条给证据；`design.md`/`tasks.md` 原文不动 |
| 删 `.bak` 删掉了唯一副本 | 删除前提是**两条核实**（不在历史 / 差异只有一次改名），读数进留痕；不可逆这件事**明写** |
| 规模数字只改一处 | 迁移计数**六个落点**逐一核对（`specs/README.md`、`INSTALL.md` ×2、根 `README.md`、`PROJECT_FEATURES.md`、本目录） |
