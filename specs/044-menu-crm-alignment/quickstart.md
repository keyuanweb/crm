# Quickstart: 菜单对标成熟 CRM 调整与规划模块验证指南

**Branch**: `044-menu-crm-alignment`

## 前置条件

- 前端开发服务运行（`VITE_PROXY_TARGET=http://localhost:8081`）；后端运行于 8081。
- 本模块无后端/迁移变更，无需重启后端。

## 验证场景

### 1. 前端验证（自动化）

```bash
cd frontend
pnpm typecheck      # 类型检查通过
pnpm lint           # 无错误
pnpm build          # 构建成功
```

**预期**: 三者全部通过。

### 2. 手动验证（菜单结构）

1. 以 admin 登录，查看左侧菜单。
2. **预期**：分组命名与归属符合方案（客户管理/销售管理/交易管理/营销中心/服务协作/工作台/数据分析/系统管理/审计与维护）。
3. 已实现模块（线索/客户/商机/报价/合同/订单/发票/工单等）入口全部保留。

### 3. 手动验证（占位项）

1. 查看"规划中"占位项（如销售 Playbook、营销自动化、客户门户等）。
2. **预期**：显示"（规划中）"标记，点击无反应（disabled）、不跳转 404。

### 4. 移动端

- 窗口 <768px：菜单拍平，占位项同样 disabled 且标记可见，无报错。

## 契约核对

- 无后端接口变更，契约无更新。
